# HA7CH

HA7CH helps build AI Native Companies: organizations where people and AI agents share business context, responsibilities, permissions, and results. Its work spans enterprise AI diagnosis and ANC deployment, practical education, creator collaboration, and investment and incubation.

For the current company introduction and consultation routes, read [HA7CH's public Skill](https://ha7ch.com/SKILL.md). For events and training, read the separate [ANC Night Skill](https://night.ha7ch.com/SKILL.md) and [ANC Camp Skill](https://camp.ha7ch.com/SKILL.md) (formerly FDE Camp). Dates, availability and terms belong to those current sources.

Built with Next.js and ready for GitHub + Vercel.

## Local Development

```bash
npm install
npm run dev
```

## Deploy

```bash
vercel deploy
```
